## Safety and data semantics

- Business Lines remains subject to the existing approved-user, email verification, module permission and column-policy gates. Presentation preferences do not grant access.
- UTC instants remain the database source of truth. New event-origin timezone context records what the client supplies at the action. Export display uses the chosen IANA timezone and separate timezone columns; neither server UTC nor export display timezone is used to invent unknown historic event-local context.
- CSV preserves readable UTF-8 values and formula-safe text. Borders, frozen panes, multiple sheets and Excel cell formats are XLSX features.
- Automated write-capable tests use an isolated loopback database whose name explicitly includes `test`. Production data and credentials are not used.
- Exact completed-file retries show the previous result. A corrected file is a new validation/import operation; a retry never repeats committed writes.
